What is OpenClaw?

OpenClaw is an AI agent platform. It follows written instructions (“skills”) and uses tools such as a web browser to complete tasks on its own.

The problem

Pre-launch website reviews meant repeating the same manual checks on every site, which was slow and could be inconsistent.

My role

Member of the company’s early core OpenClaw research team. I wrote the review skills and configured the integrations with internal systems.

What I built

  • Turned the team’s pre-launch checklist into custom OpenClaw skills that the agent follows on every site.
  • Set up browser automation to check copy, layout, responsiveness and business information, and report findings back to the team.
  • Connected OpenClaw to internal system APIs so it can run website backend tasks such as uploading products and services.
  • Kept API tokens out of prompts, skills and outputs, so credentials are never exposed.

Review workflow

  1. Website URL + team checklist
  2. OpenClaw agent + custom review skills
  3. Browser checks: copy, layout, responsiveness, information
  4. Review findings for the team

Result

Review throughput rose from one website to six in 30 minutes, reducing repetitive manual review. This figure applies specifically to website QA.

Tech in context

OpenClaw with custom skills holds the review rules. Browser automation performs the checks. Internal REST APIs handle backend tasks.
